# Security Policy

## Supported Versions

Security fixes are provided for the latest release. Upgrade to the newest version before reporting an issue that may already be resolved.

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's [Security advisories](https://github.com/leandrolid/subtitle-renamer/security/advisories) page.
2. Select **Report a vulnerability**.
3. Describe the affected version, impact, reproduction steps, and any suggested mitigation.

Please avoid accessing other people's data, destructive testing, or public disclosure while the report is being reviewed. The maintainer will acknowledge the report when practical, investigate it, and coordinate any fix and disclosure through the private advisory.

If the **Report a vulnerability** button is unavailable, contact the maintainer through the private contact methods listed on the [GitHub profile](https://github.com/leandrolid). Do not include exploit details in a public issue.

## Scope

Security concerns include unintended file overwrite or deletion, unsafe path handling, desktop privilege or capability escalation, and vulnerabilities in distributed packages. General bugs without security impact belong in the public bug report form.
